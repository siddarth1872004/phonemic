# PhoneMic 0.4.0

PhoneMic now connects over **Bluetooth only**, and both apps are lighter and
wear a new true-black look.

## Downloads

| | File |
|---|---|
| Windows 11 (22H2+) | `PhoneMic-windows-x64.zip`: unzip and run `PhoneMic.exe` (keep the `driver` folder next to it) |
| Linux, any distro (glibc 2.28+) | `PhoneMic-x86_64.AppImage`: `chmod +x`, run |
| Debian / Ubuntu / Mint | `phonemic_0.4.0_amd64.deb` |
| Fedora / openSUSE / RHEL 8+ | `phonemic-0.4.0-1.x86_64.rpm` |
| Linux, other | `PhoneMic-linux-x86_64.tar.gz` |
| Android 10+ | `PhoneMic.apk` |

## What's new

- **Bluetooth instead of Wi-Fi.** Pair the phone with the PC once, choose the
  PC in the app and tap Start. No network, IP address, router or firewall is
  involved. The link uses each system's own Bluetooth stack (BlueZ on Linux,
  the Windows Bluetooth stack), so there is no Bluetooth driver to install. The phone reconnects by itself if the link drops.
- **Still a real microphone.** The audio arrives on the PC as
  "PhoneMic Microphone", as before, in 48 kHz Opus.
- **True-black (OLED) design** on the phone and the PC, with one shared palette.
- **Lighter.** The Android app drops AndroidX and Material (framework widgets
  only; Oboe is its one library). The desktop app drops the browser mic,
  Wi-Fi discovery, USB mode and its encryption library, and release builds
  strip unused code.

## Removed

- macOS support (the macOS app, the `PhoneMic.driver` plug-in and the macOS
  build). PhoneMic now runs on Windows and Linux.
- Wi-Fi (UDP) streaming and "Find my PC" discovery.
- The browser microphone (HTTPS/WebSocket page, QR code).
- USB cable mode (`adb reverse`).
- PIN encryption: Bluetooth pairing authenticates the phone and encrypts the
  link instead.
- `phonemic-softphone`.

## Upgrading

Update **both** the phone app and the PC app: 0.4.0 phones and PCs don't talk
to 0.3.x. Pair the phone with the PC in Bluetooth settings first.

## Requirements

- Bluetooth on the PC (built in or a USB adapter the system already supports).
  Linux: BlueZ, the standard Bluetooth service.
- Windows: Windows 11, version 22H2 or newer, for the microphone driver. Until
  the driver is attestation-signed by Microsoft it needs test mode (Secure
  Boot off); the installer explains and asks first.
- Linux: PipeWire (pipewire-pulse) or PulseAudio, or ALSA
  with `snd-aloop`.
- Android 10 or newer, with Bluetooth. iPhone is not supported (iOS gives apps
  no RFCOMM).

## Known limitations

- The phone does not appear as a Bluetooth *headset* (HFP): Android apps can't
  take that role, and headset audio is 16 kHz at best. It appears as
  "PhoneMic Microphone" instead, which every app can use.
- Bluetooth adds roughly 20 to 40 ms over a wired link.
