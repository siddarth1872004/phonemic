# PhoneMic 0.4.0

PhoneMic now connects over **Bluetooth, Wi-Fi or a USB cable**. On Windows it
uses **VB-CABLE** from the app instead of a driver of its own. Both apps get a
new icon and themes.

## Downloads

| | File |
|---|---|
| Windows 10 / 11 (64-bit) | `PhoneMic-windows-x64.zip`: unzip and run `PhoneMic.exe` |
| Linux, any distro (glibc 2.28+) | `PhoneMic-x86_64.AppImage`: `chmod +x`, run |
| Debian / Ubuntu / Mint | `phonemic_0.4.0_amd64.deb` |
| Fedora / openSUSE / RHEL 8+ | `phonemic-0.4.0-1.x86_64.rpm` |
| Linux, other | `PhoneMic-linux-x86_64.tar.gz` |
| Android 10+ | `PhoneMic.apk` |

## What's new

- **Bluetooth, alongside Wi-Fi and USB.** Choose the link at the top of the
  phone app.
  - **Bluetooth:** pair the phone with the PC once, then pick the PC. It uses
    the system's own Bluetooth stack (BlueZ, or the Windows stack), so there is
    nothing extra to install.
  - **Wi-Fi:** works as before, with *Find your PC* and an optional PIN.
  - **USB:** tick **USB cable** on the PC and plug in a phone with USB debugging
    on.

  The phone reconnects by itself if the link drops.
- **VB-CABLE, built into the app (Windows).**
  - **Install VB-CABLE** downloads the free, signed cable from vb-audio.com,
    checks it really comes from VB-Audio, and runs its installer.
  - PhoneMic plays into the cable by itself.
  - **Rename to PhoneMic** makes apps list *PhoneMic Microphone* instead of
    *CABLE Output*. **Restore VB-CABLE names** undoes it.
  - If Windows makes the cable the default *speaker*, which would send every PC
    sound into the mic, PhoneMic switches back to your real speakers.
- **Themes.** Both apps have OLED black, Dark and Light themes and five accent
  colours, under **Appearance**.
- **New icon** for the Windows exe, the Linux desktop entry and the Android
  launcher. The Android icon is adaptive and supports themed icons.
- **Lighter.** The Android app drops AndroidX and Material and uses Oboe as its
  only library. The desktop app drops the browser mic, and release builds strip
  unused code.

## Removed

- PhoneMic's own Windows microphone driver, along with test mode and the
  Windows 11 22H2 requirement. VB-CABLE replaces it.
- macOS support: the macOS app, the `PhoneMic.driver` plug-in and the macOS
  build. PhoneMic now runs on Windows and Linux.
- The browser microphone: the HTTPS/WebSocket page and the QR code.
- `phonemic-softphone`.

## Upgrading

Update **both** the phone app and the PC app, because 0.4.0 doesn't talk to
0.3.x.

If you installed the 0.3.x PhoneMic driver on Windows, remove it in Device
Manager under *Sound, video and game controllers*, then install VB-CABLE from
the app.

## Requirements

- **Windows** 10 or 11, 64-bit, with VB-CABLE (installed from the app;
  donationware from VB-Audio, not shipped with PhoneMic).
- **Linux:** PipeWire (pipewire-pulse) or PulseAudio, or ALSA with
  `snd-aloop`. Bluetooth also needs BlueZ.
- **USB:** `adb` from the Android SDK platform-tools.
- **Android** 10 or newer. iPhone is not supported.

## Known limitations

- The phone does not appear as a Bluetooth *headset* (HFP). Android apps can't
  take that role, and headset audio is 16 kHz at best. The phone appears as
  "PhoneMic Microphone" instead, which every app can use.
- The VB-CABLE driver itself keeps its name ("VB-Audio Virtual Cable") because
  its signed driver package can't be changed. Only the two microphone and
  speaker names are renamed.
- The VB-CABLE install, rename and default-speaker fix are compiled in CI
  (MSVC) but have no automated tests and have not yet been tried on a wide
  range of Windows machines. Reports are welcome.
