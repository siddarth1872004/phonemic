# PhoneMic 0.3.1

PhoneMic now uses **only its own microphone**, "PhoneMic Microphone", and makes
sure every app can use it.

## Downloads

| | File |
|---|---|
| Windows 11 (22H2+) | `PhoneMic-windows-x64.zip`: unzip and run `PhoneMic.exe` (keep the `driver` folder next to it) |
| Linux, any distro (glibc 2.28+) | `PhoneMic-x86_64.AppImage`: `chmod +x`, run |
| Debian / Ubuntu / Mint | `phonemic_0.3.1_amd64.deb` |
| Fedora / openSUSE / RHEL 8+ | `phonemic-0.3.1-1.x86_64.rpm` |
| Linux, other | `PhoneMic-linux-x86_64.tar.gz` |
| macOS 11+ (Apple silicon + Intel) | `PhoneMic-macos.zip`: unzip, right-click `PhoneMic.app` → Open the first time |
| Android 10+ | `PhoneMic.apk` |

## What's new

- **No third-party drivers.** The VB-CABLE installer and the VB-CABLE /
  BlackHole fallbacks are removed. Each OS uses PhoneMic's own microphone:
  the PhoneMic driver on Windows 11, PhoneMic.driver on macOS, and the
  sound server's own modules on Linux.
- **In every app.**
  - **Make it the default microphone** (one click, every OS): apps without a
    microphone setting, and "Default" in apps that have one, now use PhoneMic.
    On Windows it becomes the default for calls too (the "communications" role
    Teams, Discord and Skype use).
  - Windows: the driver now declares itself as a capture device explicitly and
    reports its microphone as always plugged in, so Windows lists it in every
    app as *Microphone (PhoneMic Microphone)*.
  - Linux: **Keep it when PhoneMic is closed** registers the microphone with
    PipeWire/PulseAudio, so it exists from login on, like a hardware mic, and
    apps opened before PhoneMic list it too.
- Command line: `phonemic-receiver --make-default`, `--keep-mic on|off` (Linux),
  and `phonemic-vmic-check --setup --default` to check the whole path.

## Requirements

- Windows: Windows 11, version 22H2 or newer. Until the driver is
  attestation-signed by Microsoft it needs test mode (Secure Boot off); the
  installer explains and asks first. Windows 10 is not supported.
- macOS 11 or newer. Linux: PipeWire (pipewire-pulse) or PulseAudio, or ALSA
  with `snd-aloop`.

## Verified in CI

The microphone is checked end to end (a tone played in must come back out, by
name and as the system default) on macOS with PhoneMic.driver installed, on
Ubuntu (PulseAudio), and on Debian, Fedora, Arch and openSUSE (PipeWire). The
Windows driver is built and packaged in CI; it has not yet been loaded on a
wide range of hardware, so please report how it works for you.
