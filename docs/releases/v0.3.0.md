# PhoneMic 0.3.0

Turn your phone into a real wireless microphone for your PC. This release
rewrites the desktop app in C++, gives PhoneMic **its own virtual microphone on
every OS** (no VB-CABLE or BlackHole needed), and ships for every Linux distro.

## Downloads

| | File |
|---|---|
| Windows 10/11 | `PhoneMic-windows-x64.zip`: unzip and run `PhoneMic.exe` (keep the `driver` folder next to it). `PhoneMic.exe` alone also works with VB-CABLE. |
| Linux, any distro (glibc 2.28+) | `PhoneMic-x86_64.AppImage`: `chmod +x`, run |
| Debian / Ubuntu / Mint | `phonemic_0.3.0_amd64.deb` |
| Fedora / openSUSE / RHEL 8+ | `phonemic-0.3.0-1.x86_64.rpm` |
| Linux, other | `PhoneMic-linux-x86_64.tar.gz` (`bin/` + `share/`) |
| macOS 11+ (Apple silicon + Intel) | `PhoneMic-macos.zip`: unzip, right-click `PhoneMic.app` → Open the first time |
| Android 10+ | `PhoneMic.apk` |

Any phone can also use the **browser mic**: tick *Browser mic* in the PC window
and scan the QR code.

## Highlights

- **Its own microphone everywhere — "PhoneMic Microphone".**
  - *Windows 11 (22H2+):* PhoneMic's ACX driver. Click **Install PhoneMic
    driver**; it explains and asks before turning on test mode (needed until the
    driver is signed by Microsoft; Secure Boot must be off), signs the driver
    with a certificate made on your PC, and installs it. VB-CABLE stays
    available as a fallback (Windows 10, or no test mode).
  - *macOS:* PhoneMic.driver, a Core Audio plug-in (no kernel extension).
    Click **Install PhoneMic driver** and enter your password.
  - *Linux:* created automatically through PipeWire or PulseAudio, no `pactl`
    needed; plain-ALSA systems can use the kernel loopback (`snd-aloop`).
- **Every Linux distro:** one portable build (X11 + native Wayland) as AppImage,
  .deb, .rpm and tarball; CI installs it on Debian 12, Ubuntu 22.04, Fedora,
  Arch, openSUSE and Rocky Linux 8 and checks the microphone really carries
  audio on each distro's default sound server (PulseAudio or PipeWire).
- **Opus compression** (~48 kbps instead of 768 kbps) with forward error
  correction that rebuilds lost packets. On by default.
- **USB cable mode:** bad Wi-Fi? Plug the phone in; PhoneMic sets up
  `adb reverse` itself.
- **Find my PC:** the phone finds the PC on the Wi-Fi; no IP typing.
- **Browser mic** built into the app (HTTPS + QR code + pairing code).
- **Drift compensation:** no creeping delay or periodic clicks over long calls.
- **Tells you what's wrong:** the PC reports back to the phone (wrong PIN, PC
  busy, not running…).
- **Encryption:** the same PIN on both ends → XChaCha20-Poly1305 with Argon2id
  keys; with a PIN set, unauthenticated audio is refused.

## Fixes

About 60 bugs from 0.2 are fixed, including a silent microphone on Linux, the
phone's capture dying when a headset was plugged in, a PIN that didn't stop
unencrypted audio from being injected, a brute-forceable PIN key, and a first
driver draft that would have crashed Windows. The full list with causes is in
[docs/AUDIT.md](https://github.com/siddarth1872004/phonemic/blob/main/docs/AUDIT.md).

## Upgrading from 0.2

The desktop app is a new C++ program; settings start fresh. Phones running the
0.2 app still work (legacy v1 packets are accepted), but update the phone app
for Opus, USB mode, discovery and status feedback.

## Known limitations

- The Windows driver needs test mode until it is attestation-signed by
  Microsoft, and it has not yet been tested on a wide range of hardware: please
  report how it works for you. VB-CABLE remains available.
- Linux distributions without glibc (Alpine, other musl systems) need a source
  build.
- No Bluetooth transport (USB covers the no/bad Wi-Fi case at lower latency).
