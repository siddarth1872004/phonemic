# PhoneMic 0.5.0

A **Soundboard** in the phone app: play MyInstants sounds straight into your
PhoneMic microphone, on top of your voice.

## Downloads

| | File |
|---|---|
| Windows 10 / 11 (64-bit) | `PhoneMic-windows-x64.zip`: unzip and run `PhoneMic.exe` |
| Linux, any distro (glibc 2.28+) | `PhoneMic-x86_64.AppImage`: `chmod +x`, run |
| Debian / Ubuntu / Mint | `phonemic_0.5.0_amd64.deb` |
| Fedora / openSUSE / RHEL 8+ | `phonemic-0.5.0-1.x86_64.rpm` |
| Arch Linux | `cd packaging/arch && makepkg -si` from the source |
| Linux, other | `PhoneMic-linux-x86_64.tar.gz` |
| Android 10+ | `PhoneMic.apk` |

## What's new

- **Soundboard.** Tap **Soundboard** in the phone app to open MyInstants. Start
  streaming, then tap any sound: everyone listening to PhoneMic Microphone hears
  it together with your voice, and the phone's speaker stays silent.
  - **Level** sets how loud sounds are against your voice; a limiter keeps the
    mix from clipping.
  - A new sound replaces the one playing; **Stop** cuts it off.
  - Mute silences sounds too.
  - Streaming keeps going while you switch between screens.

The PC app is unchanged apart from its version number; any 0.4 PC app works
with this phone app.
