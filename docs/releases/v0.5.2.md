# PhoneMic 0.5.2

A new app icon to match the 0.5.1 look. No changes to audio or the protocol,
so a 0.5.1 phone and a 0.5.2 PC (or the reverse) work together.

## Downloads

| | File |
|---|---|
| Windows 10 / 11 (64-bit) | `PhoneMic-windows-x64.zip`: unzip and run `PhoneMic.exe` |
| Linux, any distro (glibc 2.28+) | `PhoneMic-x86_64.AppImage`: `chmod +x`, run |
| Debian / Ubuntu / Mint | `phonemic_0.5.2_amd64.deb` |
| Fedora / openSUSE / RHEL 8+ | `phonemic-0.5.2-1.x86_64.rpm` |
| Arch Linux | `cd packaging/arch && makepkg -si` from the source |
| Linux, other | `PhoneMic-linux-x86_64.tar.gz` |
| Android 10+ | `PhoneMic.apk` |

## What's new

- **New icon**: a light mic inside an orange LED level ring on a graphite
  tile, on the Windows .exe, the Linux window and tray, and the Android
  launcher. Android's themed icons get a matching monochrome version. At
  small sizes the ring is dropped and the mic drawn larger.
- README and START-HERE describe the new layout (the Start ring, the
  Routing and Faceplate panels, the separate mutes).

## Installing over an older version on Android

Release APKs are signed with a different key on every build, so Android
refuses to install one over another. Uninstall PhoneMic first; your settings
are lost.
