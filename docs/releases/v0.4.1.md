# PhoneMic 0.4.1

Closing the PhoneMic window no longer stops your microphone: PhoneMic keeps
running in the **system tray**.

## Downloads

| | File |
|---|---|
| Windows 10 / 11 (64-bit) | `PhoneMic-windows-x64.zip`: unzip and run `PhoneMic.exe` |
| Linux, any distro (glibc 2.28+) | `PhoneMic-x86_64.AppImage`: `chmod +x`, run |
| Debian / Ubuntu / Mint | `phonemic_0.4.1_amd64.deb` |
| Fedora / openSUSE / RHEL 8+ | `phonemic-0.4.1-1.x86_64.rpm` |
| Arch Linux | `cd packaging/arch && makepkg -si` from the source |
| Linux, other | `PhoneMic-linux-x86_64.tar.gz` |
| Android 10+ | `PhoneMic.apk` |

## What's new

- **Stays in the tray.** Closing the window hides it and the phone keeps
  streaming. Click the tray icon to show or hide the window; right-click it
  for *Show PhoneMic* and *Quit PhoneMic*. On Linux this works with any tray
  that supports StatusNotifierItem (KDE Plasma, GNOME with the AppIndicator
  extension, most others). Without a tray, closing quits as before.
- **One PhoneMic at a time.** Starting PhoneMic while it is already running
  shows its window instead of opening a second copy.
- **Arch Linux package recipe** in `packaging/arch/PKGBUILD`.

## Fixed

- Linux (Wayland): the window could freeze after being re-shown or minimised.

The phone app is unchanged apart from its version number.
